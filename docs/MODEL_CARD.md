# Model Card

## Model
Random Forest classifier wrapped in a scikit-learn preprocessing pipeline.

## Intended use
Educational demonstration and portfolio project for failure/no-failure classification from AI4I-style operating measurements.

## Inputs
Machine type, air temperature, process temperature, rotational speed, torque and tool wear, plus engineered features.

## Output
Predicted class (no failure/failure) and estimated probability for the failure class.

## Training data
UCI AI4I 2020 Predictive Maintenance Dataset. This is synthetic industrial-style data.

## Evaluation
Metrics are generated by running `python -m src.train` and saved in `outputs/metrics/`. Record actual results from your own run.

## Limitations and risks
- Dataset distribution may not represent real machinery.
- Class imbalance affects interpretation of accuracy.
- Probability estimates are not guarantees.
- The model does not estimate remaining useful life.
- Not intended for safety-critical or unattended maintenance decisions.
